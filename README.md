# Kishan Buha Portfolio

Welcome to the portfolio of **Kishan Buha**, a software developer specializing in backend databases and frontend interfaces. This project showcases a modern, responsive, and visually appealing portfolio website built with **HTML**, **CSS**, and **JavaScript**.

## Features

- **Home Page**: Introduction and overview of Kishan's expertise.
- **About Page**: Detailed information about Kishan's background and technology stack.
- **Projects Page**: A showcase of completed projects with links to GitHub repositories.
- **Contact Page**: A form to reach out directly to Kishan via email.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling, including advanced glassmorphism effects.
- **JavaScript**: For interactivity, including animations and form handling.
- **Bootstrap 5**: For responsive design and layout.
- **Intersection Observer API**: For scroll animations.
